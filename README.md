# Docker Deployment Automation

A practical DevOps project that automates
Docker container deployment using Bash scripting.

## Technologies Used

- Ubuntu Linux
- Docker
- Bash Scripting
- Nginx
- HTML

## Project Features

- Docker installation validation
- Docker daemon verification
- Automated image building
- Existing container management
- Automated container deployment
- Deployment verification
- Error handling and logging
